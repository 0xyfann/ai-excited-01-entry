# Moon Crossing

A tiny sailboat with warm, glowing sails crosses the face of an enormous low full moon, floating on a calm night sea. Deep indigo sky, soft aurora ribbons and scattered stars frame the pale-gold moon, while a broken path of moonlight shimmers on the water below the boat. One quiet, thrilling moment: the smallest boat, the biggest moon.

Rendered entirely by `main.py` (Python standard library only, deterministic, no network) as a 960x960 PNG.
